# YEuhub.ME

个人工作与生活工具，使用 GitHub Pages 托管静态页面。

## 页面入口

| 地址 | 内容 |
| --- | --- |
| `/` | 工作与生活总首页 |
| `/email-check/` | 邮件内容诊断 |
| `/country-query/` | 目标国家查询 |
| `/industry-keyword/` | 行业关键词速览 |
| `/fitness/` | 健身记录 |

`index (1).html` 等带编号的根目录文件是保留的旧副本。正式首页是根目录的 `index.html`，子页面应更新各自目录内的 `index.html`，避免再次覆盖总首页。

健身记录继续使用 `yeuhub_fitness_records_v1`。在同一域名、同一浏览器中，从旧首页切换到 `/fitness/` 后仍可读取已有记录。数据不会自动同步到其他浏览器或设备。

## 验证

使用 Node.js 18 或以上版本，无需安装依赖：

```sh
node --test tests/site.test.cjs
```

检查覆盖入口链接、脚本语法、原有密码入口、训练写法解析、连续训练统计、旧记录兼容、保存失败和删除确认，以及图片确认框的键盘行为。这些检查不包含真实浏览器渲染或第三方 OCR 服务测试。
