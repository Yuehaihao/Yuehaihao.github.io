# YEuhub.ME

海浩的工作与生活空间，使用 GitHub Pages 托管。界面参考 Apple 中国官网的留白、系统字体、浅色卡片和按钮层级，保持 YEuhub 自己的品牌与内容。

## 当前页面

| 地址 | 内容 |
| --- | --- |
| `/` | 个人首页；工作区仅保留海浩 AI 入口 |
| `/agent/` | 海浩 AI 聊天界面，解锁后进入 |
| `/fitness/` | 健身记录、训练热力图和训练回顾 |

原有邮件诊断、国家查询和行业关键词三个入口已从首页移除，旧目录及带编号的历史页面保留供回退。正式首页是根目录的 `index.html`。

## 海浩 AI 的状态

**本次完成聊天前端，尚未接通模型服务或导入知识库。** 页面会明确显示准备中；未配置时，输入的问题保留在草稿中，不发送请求、不生成模拟回答。

- 首页使用原密码；验证成功直接跳转 `/agent/index.html`。
- 解锁有效期仍为 30 分钟；直接访问、过期或其他标签页锁定后返回首页入口。
- 聊天支持开场问题、中文输入法、Enter 发送、Shift + Enter 换行、停止、重试及新对话。
- 对话与草稿使用当前标签页的 `sessionStorage`，不在不同访客间共享；锁定并离开会清空。浏览器可能恢复标签页会话，结束使用时可点“锁定并离开”。
- 接入服务后才发送当前问题与最近 20 条历史消息；模型回答以纯文本显示，支持可选的资料来源链接。

配置及后端接口约定见 [agent/README.md](agent/README.md)。前端不存放模型 API 密钥。原密码门禁是静态页面的便利入口，不是服务端鉴权；后端需要独立处理访问限制及用量控制。

## 代码结构

- `assets/site.css`：首页和公共设计样式。
- `assets/access.js`：沿用原密码摘要与解锁状态。
- `assets/home.js`：首页解锁和跳转。
- `agent/`：独立聊天页面、样式、对话逻辑与公开配置。
- `fitness/theme.css`：健身页浅色主题。

健身记录继续使用 `yeuhub_fitness_records_v1`。同一域名和同一浏览器中的历史记录仍可读取；没有迁移或清空数据，也不会自动同步到其他设备。

## 验证

使用 Node.js 18 或以上版本，无需安装依赖：

```sh
node --test tests/*.test.cjs
```

覆盖页面入口与脚本语法、密码跳转/过期/存储失败、聊天未配置状态、真实接口格式（使用测试响应）、取消/重试/清空、中文输入法和安全文本渲染，以及原有健身解析与记录兼容性。测试不包含真实模型调用、浏览器渲染或第三方 OCR 服务。
