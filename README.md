# YEuhub.ME

海浩的工作与生活空间，使用 GitHub Pages 托管。界面参考 Apple 中国官网的留白、系统字体、浅色卡片和按钮层级，保持 YEuhub 自己的品牌与内容。

## 当前页面

| 地址 | 内容 |
| --- | --- |
| `/` | 个人首页；工作区仅保留海浩 AI 入口 |
| `/agent/` | AI Studio 增长漏斗图承接页，解锁后进入 |
| `/fitness/` | 健身记录、训练热力图和训练回顾 |

原有邮件诊断、国家查询和行业关键词三个入口已从首页移除，旧目录及带编号的历史页面保留供回退。正式首页是根目录的 `index.html`。

## 海浩 AI 的状态

当前已接入站主提供的 AI Studio「增长漏斗图」作为承接页，支持在线编辑层级、数值、颜色、待办事项，导出 PNG 和 PDF。首页仍保留海浩 AI 名称，原密码验证成功后直接进入该工具。

源码与构建步骤见 [projects/funnel-chart-builder/README.md](projects/funnel-chart-builder/README.md)。原聊天源码保留供后续使用，当前不启用模型对话。图表修改暂存于页面内存，刷新后恢复示例。

原密码门禁是静态页面的便利入口，不是服务端鉴权。

## 代码结构

- `assets/site.css`：首页和公共设计样式。
- `assets/access.js`：沿用原密码摘要与解锁状态。
- `assets/home.js`：首页解锁和跳转。
- `agent/`：增长漏斗图构建结果，以及保留的原聊天实现。
- `projects/funnel-chart-builder/`：AI Studio 项目源码和锁文件。
- `fitness/theme.css`：健身页浅色主题。

健身记录继续使用 `yeuhub_fitness_records_v1`。同一域名和同一浏览器中的历史记录仍可读取；没有迁移或清空数据，也不会自动同步到其他设备。

## 验证

使用 Node.js 18 或以上版本，无需安装依赖：

```sh
node --test tests/*.test.cjs
```

静态测试覆盖页面入口与脚本语法、密码跳转/过期/存储失败、聊天未配置状态、真实接口格式（使用测试响应）、取消/重试/清空、中文输入法和安全文本渲染，原聊天逻辑测试针对保留实现；以及原有健身解析与记录兼容性。测试不包含真实模型调用、浏览器渲染或第三方 OCR 服务。
